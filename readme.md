🎭 מאגר ההצגות למורי תיאטרון (Dashboard 2026)
מערכת אוטומטית לסריקה, קיטלוג והצגת לוח הופעות תיאטרון בישראל, מותאמת אישית לצרכים של מורים ורכזי מגמות תיאטרון.

🚀 הקישור ללוח החי
לחצו כאן לצפייה בדאשבורד המעודכן

📋 על הפרויקט
הפרויקט נולד כדי לפתור את הקושי של מורים למצוא הצגות רלוונטיות למגמה (קלאסיקות, חומרי לימוד ופרינג') מבלי לטבוע בלוחות הופעות עמוסים. המערכת מסננת אוטומטית הצגות בימי שלישי וסופי שבוע (שישי-שבת) כדי להתמקד בימי הלימודים.

תכונות מרכזיות:
סריקה אוטומטית: סורק 10+ אתרי תיאטרון (הקאמרי, הבימה, גשר, ניקו ניתאי, תמונע ועוד).

קיטלוג AI סמנטי: זיהוי אוטומטי של קלאסיקות (צ'כוב, מולייר), חומרי לימוד (בגרות) ושפה בימתית מעניינת (פרינג').

סינון ימים: מציג רק הופעות בימי ראשון, שני, רביעי וחמישי.

סנכרון ליומן: כפתור ייעודי להוספת כל הצגה ל-Google Calendar בלחיצת כפתור.

אוטומציה מלאה: המערכת מעדכנת את עצמה בכל יום ראשון בבוקר בעזרת GitHub Actions.

🛠 המבנה הטכנולוגי
הפרויקט מבוסס על "צינור נתונים" (Pipeline) בן 3 שלבים:

הסורק (theater_orchestrator.py): משתמש ב-Playwright ו-BeautifulSoup כדי לשלוף נתונים גולמיים.

המעבד (shula_dash.py): מפעיל את לוגיקת הקיטלוג, מנקה תאריכים ושעות, ומייצר קובץ HTML (ה-index.html).

האוטומציה (GitHub Actions): מריצה את השרשרת בענן ומפרסמת את האתר ל-GitHub Pages.

💾 מבנה הקבצים בתיקייה
.github/workflows/update.yml: פקודות הריצה של הבוט בענן.

theater_orchestrator.py: קוד הסריקה (Scraper).

shula_dash.py: קוד עיבוד הנתונים ובניית הדאשבורד.

all_theaters_schedule.json: מאגר הנתונים הגולמי (מתעדכן שבועית).

index.html: עמוד הבית של המורים (התוצר הסופי).

requirements.txt: רשימת הספריות להתקנה בשרת הענן.

✍️ איך מעדכנים את המערכת?
הוספת מילות מפתח לקיטלוג (קלאסיקות/פרינג'):
פתחו את הקובץ shula_dash.py.

עדכנו את רשימות ה-CLASSICS או ה-STUDY_MATERIALS.

בצעו Commit ו-Push ל-GitHub. האוטומציה תתעדכן בסיבוב הבא.

הרצת עדכון ידני:
במקום לחכות ליום ראשון, ניתן להפעיל את הסריקה באופן יזום:

עברו ללשונית Actions בגיטהאב.

בחרו ב-Weekly Theater Auto-Update.

לחצו על הכפתור הכחול Run workflow.
